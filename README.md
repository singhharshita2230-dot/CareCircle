# CareCircle 🌿

## A Connected Healthcare & Wellness Platform

CareCircle is a health and wellness support platform designed to connect people with verified doctors, counsellors, supportive communities, and nearby healthcare services.

## Purpose

CareCircle aims to help people receive trusted support while keeping their personal health information private.

## Main Features

- 🩺 Verified doctor and counsellor profiles
- 📞 Doctor on Call interface for chat, audio, and video consultation
- 🤝 Health support communities
- 📍 Nearby doctors, hospitals, clinics, and medical stores
- 🔒 Private health profiles and doctor access requests
- 🚨 Emergency help and nearby hospital support
- 🌱 Wellness stories and healthy lifestyle motivation

## Communities

- Diabetes & Blood Pressure
- Weight Gain / Weight Loss
- Anxiety & Depression
- Women’s Wellness
- Heart Health
- Senior & Caregiver Support
- Addiction Recovery
- General Wellness

## Technologies Used

- HTML
- CSS
- JavaScript

## Important Note

CareCircle does not provide AI medical advice. Medical guidance is provided only by verified doctors and counsellors.

## Project Status

This is a front-end micro-project. Features such as real accounts, video calling, appointments, maps, and secure medical records can be added in the future.
